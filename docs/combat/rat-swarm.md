# Rat Swarm defense

Wave defense and the Rat King boss encounter.

> **Verified against:** `<game version>` — `<YYYY-MM-DD>`

## Summary

Rat Swarms arrive on a timer, which makes them a preparation problem rather
than a reaction problem.

## Recommendation

Treat every swarm as scheduled maintenance. Because the arrival is
predictable, a swarm that goes badly is nearly always a resourcing failure
several minutes earlier — not a tactical failure during the wave itself.

Before each wave, confirm:

- Medicine stock is above the level the last wave consumed.
- Ward beds are free, not still occupied from the previous wave.
- Defensive placement matches the approach lane for this wave.
