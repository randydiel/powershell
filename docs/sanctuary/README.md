## Summary

The sanctuary is the engine: it is the only system that produces rather
than consumes. Its build order sets the ceiling for everything else.

## Recommendation

Prioritise in this order until medicine production outpaces infected
intake:

1. **Herb cultivation** — the input to everything downstream.
2. **Crafting** — converts herbs into medicine; useless without input.
3. **Medical wards** — throughput and capacity for treating the infected.

Widening the sanctuary footprint before this loop closes is the most common
way to stall out.
